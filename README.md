# C++ Data Lab 🔬

A research-focused repository dedicated to exploring the foundations of **Data Science, Scientific Computing, and Machine Learning** through C and C++.

This repository serves as a personal computational laboratory for experimenting with algorithms, researching how popular Data Science libraries work internally, and implementing mathematical and Machine Learning concepts from scratch.

## 🎯 Purpose

The goal of this repository is not simply to use Machine Learning libraries, but to understand what happens underneath them.

Experiments may include:

* Implementing Machine Learning algorithms from scratch
* Exploring numerical computing techniques
* Building mathematical operations used in Data Science
* Researching how libraries such as NumPy, Pandas, Scikit-learn, and others work internally
* Comparing custom implementations with optimized libraries
* Benchmarking algorithm performance
* Experimenting with data structures and algorithms for scientific computing
* Understanding memory, computation, and performance in Data Science systems

## 🧠 Research Philosophy

> Don't just use the library. Understand the machinery behind it.

Modern Data Science libraries abstract away many complex operations. This repository focuses on breaking those abstractions and exploring the underlying concepts.

For example:

* How can matrix operations be implemented from scratch?
* How does linear regression work without Scikit-learn?
* How are gradient descent and optimization implemented internally?
* What data structures make numerical computation efficient?
* Why are libraries like NumPy significantly faster than pure Python?
* How can C++ be used to accelerate Data Science workloads?

## ⚡ Performance Experiments

C and C++ provide an opportunity to explore performance at a lower level.

Experiments may include comparisons between:

* Python vs C++
* Custom implementations vs optimized libraries
* Different algorithms solving the same problem
* Memory-efficient vs computation-efficient approaches


## 🔨 Approach

Most experiments follow a simple research workflow:

1. Study the mathematical concept
2. Research existing implementations
3. Implement a simplified version from scratch
4. Test correctness
5. Compare performance
6. Analyze limitations and improvements
